Collaborative workflow

One model, many hands

Every action is a typed command. You in the web UI, your scripts, and your AI agent via MCP work on the same .solidcraft files—with undo, batch rollback, and clear error messages—so you can pick up where your agent left off and the other way round.

01

Build by hand or delegate a step

Create sketches, features, standard parts, and bolted connections through an MCP agent such as Claude Code, or edit geometry directly with the mouse in the embedded SolidCraft app.

02

Inspect and measure in 3D

Browse the classic feature and assembly tree, edit user parameters in a form, measure distances, face gaps, angles, and hole axes, or slice the model along X, Y, or Z.

03

Verify against sourced rules

Click any design finding to highlight the exact B-Rep face on the model. Adjust a parameter or move the feature by hand, save, and Mechvane re-checks the part and updates assembly links.

What works today

Mechvane is an early alpha for individual engineers, makers, and small and medium-sized companies. Everything below is released and ready to try in the browser demo or locally.

Files, assemblies & resilient joints

Available

Separate .solidcraft files for parts and assemblies, stored with relative paths so project folders can move freely. Sketches belong to their feature in a classic model tree. Cross-file joints and bolted connections remember their target faces: when a part edit causes a joint to jump to another bore, update_links notices and repairs it.

Standard parts & bolted connections

Available

Standard parts generated procedurally on demand: socket head cap screws (ISO 4762), countersunk screws (ISO 10642), hex bolts (ISO 4017), hex nuts (ISO 4032), washers (ISO 7089), ball bearings (DIN 625), and heat-set inserts. The bolted connection assistant drills through holes, tapped blind holes, or insert bores across parts, places fasteners with coaxial joints, and supports patterns.

Design checks with manufacturing profiles

Available

check_design checks wall thickness, hole edge distance, countersink clearance, thread engagement depth (by material, e.g. 1.0 × d in steel, 2.0 × d in soft aluminium), and printability overhangs for 3D printing and CNC milling. Choose the manufacturing profile, build direction, and material right on the Check page.

Web UI: parameters, measure & section

Available

Change user parameters and feature dimensions in a form (applied together or not at all). Click in the 3D view to measure point distances, parallel face gaps, angles, hole diameters, and axis distances. Cut the model along X, Y, or Z with a section slider, or switch to the embedded SolidCraft web app to model by hand.

MCP server for AI agents

Available

Connect Claude Code or another MCP client via mechvane mcp. Provides tools for parts, assemblies, joints, semantic geometry queries (find for faces, edges, and holes), in-place part editing, standard parts, bolted connections, ISO 286 fits (iso_fit), design checks, and export_gltf with materials for Blender and three.js.

Open knowledge catalog

Engineering knowledge with sources

Design checks should not guess, and an AI agent should propose what an experienced mechanical engineer would. Mechvane ships an open, machine-readable knowledge catalog where every number carries its source and verbatim quotation.

  • Every value traced to a source: Standard values from freely accessible sources, public engineering handbooks, and manufacturer datasheets, with automated source verification.
  • Explicit scope and severity: Each rule records the applicable material, manufacturing process, feature type, rationale, exceptions, and whether a violation is an error or a hint.
  • First 16 materials included: Structural and stainless steels, aluminium alloys, grey cast iron, brass, POM, PA6, PLA, and PETG—with density, stiffness, strength, hardness, and thermal values ready to assign in SolidCraft so mass and thread-depth checks use the part's material.

Quick start

Get started

Explore the example models immediately in the browser live demo with nothing to install, or run Mechvane locally in three commands.

1. Install and open the local UI

Python ≥ 3.11

mechvane setup downloads the pinned SolidCraft CLI and web app (about 90 MB) and verifies their SHA256 checksums. After setup, everything runs locally and offline. 

pip install mechvane
mechvane setup      # SolidCraft CLI & web app (~90 MB)
mechvane ui --demo  # example models in an app window

Open your own project folder with mechvane ui my-project/, or run mechvane shortcut to create a start menu entry.

Platforms: Tested on Linux and Windows 11 (x64); macOS is expected to work, not yet tested.

2. Connect an AI agent via MCP

.mcp.json

Add Mechvane as an MCP server in your project directory so an agent such as Claude Code can build parts, assemble joints, and run design checks on your files: 

{
  "mcpServers": {
    "mechvane": {
      "command": "mechvane",
      "args": ["mcp", "--workspace", "./workspace"]
    }
  }
}
Example prompt

“Build an 80×40×8 plate with four M5 clearance holes, bolt it to a bracket and check the design.”

Foundation

Built on SolidCraft

Mechvane builds on SolidCraft (Rust, Apache-2.0), an open parametric CAD kernel and application where “everything is a command”, with a built-in MCP server. SolidCraft stays unchanged as a dependency; Mechvane adds its mechanical engineering layer—separate part and assembly files with link verification, feature-owned sketches, procedural standard parts, bolted connections, and sourced design rules—on top.
