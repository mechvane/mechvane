## New
- **Plugins, first version.** SolidCraft can run sandboxed WebAssembly plugins. A plugin works only through SolidCraft's own commands, the same ones scripts and AI agents use, and only with the permissions you grant. It has no network access, and fuel and memory limits stop a runaway plugin. One plugin run is one undo step. The plugin API is `craft:plugin@0.1.0`. This first version is experimental (#15112).
- **Install a plugin from its .zip** with Install plugin… in Preferences › Plugins or the Plugins menu. It shows what the plugin asks for before installing (#15644).
- **A Plugins menu** runs installed plugins; each one gets a dialog built from its parameters (#15673).
- The first plugin is out: [SolidCraft Gears](https://github.com/bherbruck/solidcraft-gears), an involute gear generator. Download its .zip from its releases and install it in Preferences › Plugins.

### v0.40.0 (Vorabversion, 2026-11-11)
**SolidCraft 0.40.0 runs its modeling on a new geometry kernel, solidcore. Designs from every earlier version open in it and rebuild their timeline on the new kernel. Designs saved in 0.40.0 use format 53, which 0.30.1 and older can't open, so keep a copy of anything you care about before you save it here.**

SolidCraft is open-source parametric 3D CAD in Rust: sketch, constrain, extrude, and change a parameter to watch the timeline rebuild. [Website](https://solidcraft.io) · [documentation](https://docs.solidcraft.io/) · [try it in the browser](https://solidcraft.io/app) · [Discord](https://solidcraft.io/discord) · [issues](https://github.com/tangency-labs/solidcraft/issues) · [roadmap](https://github.com/tangency-labs/solidcraft/blob/main/ROADMAP.md).

This is the first stable release since 0.30.1. It went through four release candidates, and these notes cover everything since 0.30.1. If you tried the candidates, the changes since rc.4 are at the end.

## A new geometry kernel
Booleans, fillets, chamfers, shells, threads, sweeps and lofts now all run on [solidcore](https://github.com/tangency-labs/solidcore), a B-rep kernel in safe Rust based on NVIDIA's SMLib (from [USD BRep](https://github.com/NVIDIA-Omniverse/usd-brep)). It's the only kernel in this build; there's no setting to go back. solidcore now lives in SolidCraft's own repository, so a kernel fix and the app change that needs it land together.

- **Earlier designs rebuild on solidcore when they open.** A design can come out a little differently, with different face or edge counts. A feature that no longer builds reports an error and doesn't take the rest of the design down with it.
