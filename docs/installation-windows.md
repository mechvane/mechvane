# Mechvane: Installation unter Windows

Diese Anleitung wurde durch die gemeinsame Installationsanleitung für Windows und Linux abgelöst:

- **[docs/installation.md](installation.md)** — Installation in einer venv (`pip install --pre mechvane`), `mechvane setup`, Claude Code / MCP (`mechvane mcp`), Anschluss an das offene SolidCraft-Fenster (`connect_window`) und erster Test.

*(Die frühere Web-UI `mechvane ui` ist entfernt; Mechvane arbeitet direkt am laufenden SolidCraft-Fenster.)*
